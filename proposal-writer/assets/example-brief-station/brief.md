# D站

| 项目 | 内容 |
|---|---|
| 站名 | 驰远重卡超充 D站 |
| 充电桩 | **8 个**（效果图上要全部体现） |
| 运营用房 | **两层**，放在出口一侧 |
| 出入口 | 开放式，**不要道闸** |
| 地面 | 出入口水泥硬化，其余铺碎石 |
| 现场照片 | 【待补：D站现场照片】 |
| 平面规划 | 【待补：平面规划图（运营用房位置以规划为准）】 |

## 布局要求

1. 运营用房做两层，放出口一侧；减少 8 个小车停车位，运营用房往里挪。
2. 运营用房周边加晾衣架。
3. 出入口做开放式，取消道闸。
4. 去掉四周围栏。
5. 地面除了出入口做水泥硬化，其余都铺碎石。

## 导视要求

1. 全套导视按**B站**的导视清单数量出，站名换成D站，不用另做清单。
2. 不做精神堡垒，入口改成**双面铁板入口牌**：原有站名保留，下方加「驰远·D站」。

# E站

| 项目 | 内容 |
|---|---|
| 站名 | 驰远重卡超充 E站 |
| 充电桩 | **24 个**（效果图上要全部体现） |
| 运营用房 | **一层**，共 7 间；门牌【待补：7 间门牌名称】 |
| 出入口 | 敞开式，**不需要道闸** |
| 现场照片 | 【待补：E站现场照片】 |

## 布局要求

1. 运营用房做一层，房后预留 2—3 米做电动车车位，不搭棚子。
2. 在充电位停的重卡**车头都朝向充电桩**；右上方重卡停车位的重卡车头也调转过来。

## 导视要求

1. 全套导视按**A站**的导视清单数量出，站名换成E站。
2. 新增站外提示牌，设在距入口 500 米处：

| 项目 | 内容 |
|---|---|
| 尺寸 | 2m × 3m |
| 颜色 | 品牌色（品牌蓝底 + 白字） |
| logo | 左上角，品牌 logo |
| 正文 | 重卡充电站，前方500米 |
