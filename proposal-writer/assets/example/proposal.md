# 项目概述

> [!一句话方案] 2027 年 3 月 15 日—17 日，在成都太古里打造 600㎡「城市山径」快闪空间，用一条可走完的 10 分钟「微型山径」发布轻户外新品系列，以现场体验带动线上种草，目标 3 天到场 2.4 万人次、全网曝光 3000 万、新品首月销售 1200 万元。

| 项目 | 内容 |
|---|---|
| 活动名称 | 把山带进城 · 野径 2027 春季新品发布 |

| 目标人群 | 25—35 岁城市白领，周末有轻徒步、露营习惯 |
| 总预算 | 180 万元 |

# 背景与目标

## 市场背景

轻户外正在从「装备圈」走向「生活方式」。城市年轻人买冲锋衣不再只为登山，而是通勤、周末、短途旅行一衣多穿。野径过去 3 年的销售里，**非专业户外场景的购买占比从 31% 涨到 58%**，但品牌认知仍停留在「专业登山装备」。

## 项目目标

1. **品牌目标**：把「专业登山」的认知扩展到「城市里的轻户外」，活动后品牌联想中「通勤 / 日常」提及率从 12% 提升到 25%。
2. **销售目标**：新品系列首月 GMV 1200 万元，其中活动带动的线上订单占 30%。
3. **传播目标**：全网曝光 3000 万，小红书笔记 2000 篇以上。

# 洞察分析

## 目标人群画像

我们的核心人群是「想出去但出不去」的城市白领：工作日被困在写字楼，周末最多能挤出半天到一天。他们需要的不是攀登珠峰的装备，而是**一件下班就能直接去爬城郊小山的衣服**。

| 维度 | 描述 |
|---|---|
| 年龄 / 收入 | 25—35 岁，月收入 1.2—2.5 万元 |
| 户外频次 | 每月 1—2 次城郊轻徒步 / 露营 |
| 购买动机 | 好看能日常穿 > 功能参数 |
| 信息渠道 | 小红书、抖音、户外社群 |

# 核心创意

## 创意主题：把山带进城

在商场中庭搭一条 10 分钟就能走完的「微型山径」：碎石路、木栈道、溪流声、山顶观景台依次展开，每一段对应新品的一个使用场景。走完全程的人在「山顶」拿到自己的徒步证书和新品试穿体验。

## 体验动线

1. **起点 · 城市通勤段**：从写字楼场景出发，试穿新品通勤冲锋衣。
2. **碎石路段**：脚感明显的碎石路面，体验新品徒步鞋的抓地力。
3. **溪流段**：雾化喷淋模拟小雨，现场验证面料防泼水。
4. **山顶观景台**：拍照打卡点，领取「城市登山证书」，扫码完成种草笔记即得优惠券。
