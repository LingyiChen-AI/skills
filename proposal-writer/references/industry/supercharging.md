# 行业包：超充站 / 充电站企划

用户提到超充站、充电站、充电桩、液冷超充、光储充、换电站、「油转电」、充电场站运营时，按本文件写。
本文件**优先于** `outlines.md` 的通用模板，通用写作规则（`writing-rules.md`）照常适用。

配套文件：
- 行业数据（带出处、可靠性分级）→ [supercharging-data.md](supercharging-data.md)
- 投资收益测算（公式、默认假设、`finance.py` 用法）→ [supercharging-finance.md](supercharging-finance.md)

调研依据：2026-11 全网调研，报告原文不随 skill 打包。

## 1. 先判断是哪类企划

| 场景 | 典型说法 | 读者 | 核心问题 |
|---|---|---|---|
| A 建站可研 / 立项 | 可研、立项、投资分析、要不要建、建站方案 | 投委会、老板、银行 | 能不能回本 |
| B 补贴申报 | 申报补贴、奖励资金、资金申请报告 | 发改委、工信、能源主管部门 | 是否符合申报条件，申请多少钱 |
| C 场地合作提案 | 跟商场 / 物业 / 停车场 / 加油站 / 服务区谈合作、招商 | 场地业主 | 业主能拿到什么 |
| D 开业活动 | 开业、试运营、开站活动、引流 | 运营团队、老板 | 开业首月把量拉起来 |
| E 年度运营营销 | 年度运营方案、营销方案、会员方案、提升利用率 | 运营团队、老板 | 利用率和收入怎么涨 |

一句话需求说不清的，按「建站方案 → A，开业 / 活动 → D，运营 / 营销 → E」判断。混合需求以一个为主，从另一个借章节
（例如「新站开业 + 首年运营」= D 为主，借 E 的会员和 B 端章节）。

## 2. 输入体检（写之前做）

下面这些是**具体站点的事实**，用户没给就写占位符 `【待补：xxx】`，**不能编**，并全部列进附录「假设与待确认事项」：

城市、站点地址、场景类型（商圈 / 交通枢纽 / 高速服务区 / 物流园 / 加油站 / 社区）、车位数、超充主机台数 × 单机功率、
超充终端和快充终端枪数、变压器容量和可用余量、租期、租金或分成方式、本地服务费市场价、本地分时电价、目标客群。

必须问用户的只有一项：**主体是谁**（哪家运营商 / 车企 / 场地方）。其余缺失项可以带默认假设写，测算用
`supercharging-finance.md` 的默认值，并在「关键假设」表里标「默认假设，待确认」。

固定写法：
- 规模：「总装机 X MW = N 台主机 × X kW；超充终端 N 把（单枪最大 X kW）；快充终端 N 把；车位 N 个；储能 X kW / X kWh」。
- 「超充」口径：「单枪 ≥480kW（参照深圳 DB4403/T 433-2024、重庆超充技术指南）」。低于 480kW 的写「大功率快充」，不要叫超充。
- 设施数量的单位：国家能源局 2025 年起按「枪」计、单位「个」；车企、运营商常按「座（站）」「台（主机）」计。**三种单位不能混算**。

## 3. 各场景大纲

下面是建议结构，参考了国家发改委《政府投资项目可行性研究报告编写通用大纲（2023 年版）》和公开的充电项目可研案例。
按需删减，正文 6—10 章。每章的「必备图表」在 ```chart 里画；测算章节直接用 `finance.py` 生成。

### A 建站可研 / 立项

| 章节 | 必写要点 | 必备图表 |
|---|---|---|
| 项目概述 | 站名、地址、规模（按固定写法）、总投资、工期、核心指标 | 提示框「一句话方案」+ 主要技术经济指标表（来自 finance.md） |
| 背景与必要性 | 国家政策带文号（632 号文、三年倍增方案、1721 号文）；省市政策；本地超充规划 | 全国充电设施保有量折线（数据见 data.md）；政策时间表（表格） |
| 需求分析 | 服务半径内 800V 高压车型、网约车 / 出租车 / 物流车需求；竞品功率段、价格、排队；推出目标站级日电量 | 竞品对比表；客群构成环形图（用户给数才画） |
| 选址与要素保障 | 2—3 个候选点打分比选；电力接入（变压器余量、10kV 距离、增容费、报装周期）；产权与租期（租期要 ≥ 回收期） | 候选点雷达图（`radar`，权重写「企业自定」）；电力接入条件表 |
| 建设方案 | 全液冷、功率池分配、800V 兼容、储能「以储代扩」、消防、平台接入；工期节点 | 平面布置与动线示意（```image，无文字）；设备清单表；工期甘特图 |
| 运营方案 | 自营 / 委托运营；定价（电费 + 服务费、分时）；占位费；人员；KPI | 定价表；KPI 表 |
| 投资与财务 | `<!-- include: finance.md -->`：指标表、投资构成、关键假设、分年测算、累计现金流、情景、敏感性 | 由 finance.py 生成 |
| 风险管控 | 风险识别 → 管控措施 → 应急预案，至少覆盖：电力接入、价格战、利用率爬坡慢、租期短、设备迭代、安全 | 风险登记表（类别 / 描述 / 可能性 / 影响 / 预警指标 / 措施 / 责任人） |
| 结论与建议 | 句式必须和测算一致：FNPV>0、FIRR>折现率、回收期 ≤ 测算期且 ≤ 租期才写「可行」；否则写「有条件可行」并列条件 | — |

工期甘特图要排进申报节点：备案 → 电力报装 → 施工 → 竣工验收 → 接入市级监管平台 → 投运满 N 日 → 补贴申报。
大功率设施电力接入一般不少于 6 个月，排期时别压缩这一段。

### C 场地合作提案（商场、物业、停车场、加油站、服务区）

| 章节 | 必写要点 | 必备图表 |
|---|---|---|
| 一页摘要 | 业主得到什么（年收益区间、客流、形象），业主出什么（车位、电力配合、施工配合），合作期限 | 提示框 |
| 我方介绍 | 已运营站点、平台和运维能力（用户提供） | — |
| 场地评估 | 车位、动线、变压器余量、周边需求 | 场地条件表 |
| 建设方案 | 平面布置；施工周期；对现有经营的影响（围挡、断电窗口） | 场站概念图（```image）；施工排期甘特图 |
| 合作模式比选 | 固定租金 / 按电量每度分成 / 服务费比例分成 / 保底 + 分成 / 合资共建，逐项比收益、风险、投资方、产权、期满处置 | 模式比选表 |
| 业主收益测算 | 低 / 中 / 高三档站级日电量 → 业主年收入 | 三档柱状图（`bar`）+ 表 |
| 附加价值 | 充电停留 20—30 分钟带动消费、停车费联动、会员互通、绿色形象 | — |
| 责任划分 | 运维、告警、消防、保险、事故责任 | 责任表 |
| 合同要点 | 期限（对齐 632 号文鼓励的「10 年以上」）、调价机制、提前解约补偿、设备期满归属、电费结算 | 条款表 |

- 业主收益 = 年电量 × 每度分成（或服务费 × 分成比例）。三档电量用 `finance.py` 跑低 / 中 / 高利用率得到，别拍脑袋。
- 分成比例公开资料只有一个可靠案例（济南：服务费的 30% 给物业），**不能写成行业标准**，只能写「参考案例」。
- 加油站版加「油电协同」和防爆区、安全间距合规说明；**间距数值必须来自用户提供的规范依据**，不能自拟。

## 4. 写作禁区

**数字禁区**（找不到就写占位符或「企业自定目标」）：
1. 不编具体站点的车流、需求量、竞品价格、变压器余量、租金。
2. 不编补贴标准。「上海 480kW 超充补贴 1200 元/kW」「深圳最高 1500 万」都没有官方出处；补贴数只能来自用户提供的当年当地文件。
3. 不把「全国服务费 0.5 元/kWh 封顶」写成事实，没有核实到官方原文。
4. 不引用厂商宣传的「1.3—2 年回本」「日均利用率 45%」「8 枪站总投资 18 万」这类与权威口径矛盾的数字。
5. 不用「单枪日电量」推超充站收入，用站级日电量和功率利用率（`finance.py` 就是这么算的）。
6. 不把「台」「枪」「座」混算；不拿 632 号文的「10 万台」和「18 万枪」比较后写「已超额完成」。
7. 不编会员复充率、ARPU、获客成本、开业转化率的**行业基准**，公开资料里没有；只能写企业自定目标。
8. 不编网约车平台协议价折扣、高速服务区分成比例；不把网上 15%—50% 的分成区间写成行业标准。
9. 不编储能 2026 年单价、3C 认证和 GB 46519-2025 的具体条款。
10. 不编运营商（特来电、理想、华为等）没有披露的单站财务数据和内部选址权重。
11. 不编消防安全间距、防爆区距离等合规数值。
12. data.md 里标 C 级的数据只能写进背景，并注明「据行业报道」，不能进测算。

**写法禁区**：
- 自定的选址权重注明「企业自定，无公开出处」；推算值注明「推算」。
- 结论必须和测算一致：`finance.py` 的 `warnings` 不为空时，结论不能写「可行」，要把每条警告写进风险章节并给对策。
- 每份测算都要带「无补贴情景」（有补贴时）和「悲观情景」，`finance.py` 会自动生成。
- 需求不要按新能源车总量算：能用超充的是 800V 高压车型（北京 2024 年底约占新能源车 8.5%）和运营车。
