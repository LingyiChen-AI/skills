# proposal.md 语法

企划书源文件是普通 Markdown 加两个扩展块（```chart、```image）。只支持下面列出的写法，别的语法（嵌套引用、HTML、脚注、斜体）不会被渲染。

## frontmatter

```yaml
---
title: 野径 2027 春季新品发布会企划书     # 必填，封面标题、页眉、文件名
subtitle: 「把山带进城」—— 轻户外系列城市快闪发布
client: 野径户外                          # 封面「客户 / 项目方」
author: 品牌策划部                        # 封面「编制单位」
date: 2026-11-11
version: V1.0
theme: "#1F6F5C"                          # 主色，标题、表头、提示框都用它
cover_image: images/cover.png            # 可选，封面主视觉
cover_prompt: 封面图的生图提示词           # 可选，cover_image 不存在时用它生成
cover_ratio: "16:9"                       # 可选
confidential: 本方案仅限内部使用          # 可选，封面底部小字
kicker: 企 划 书  ·  PROPOSAL            # 可选，标题上方的小标签
numbering: true                           # 可选，章节自动编号（01、1.1），默认开
filename: 自定义输出文件名                # 可选
---
```

## 正文

| 写法 | 效果 |
|---|---|
| `# 章标题` | 一级章节：另起一页，大号编号 01、02……，**不要自己写编号** |
| `## 小节` | 二级标题，自动编号 1.1、1.2 |
| `### 小标题` | 三级标题，不编号 |
| 普通段落 | 正文，空行分段 |
| `**加粗**` | 加粗并用主色，用来标出关键数字和结论，每段最多 1—2 处 |
| `- 条目` / `1. 条目` | 列表，缩进两个空格为二级 |
| `\| 表格 \|` | 表格，第一行是表头。整列都是数字时自动右对齐 |
| `表：表题` | 写在表格**前一行**，作为表题（自动编号「表 3-1」） |
| `> [!标题] 内容` | 提示框（主色浅底 + 左竖条），多行就用多行 `>` |
| `![图注](images/a.png)` | 插图，图注自动编号「图 3-1」 |
| `![图注\|12](images/a.png)` | 插图并指定宽度 12cm（默认通栏 16.6cm） |
| `<!-- pagebreak -->` | 强制换页，一般用不到 |
| `<!-- include: finance.md -->` | 把同目录另一个 md 的内容原样插到这里（单独一行）。用于 `finance.py` 生成的测算章节，改假设重跑后自动更新 |

## ```chart 统计图

````
```chart
{"type":"donut","items":[{"name":"搭建","value":78},{"name":"传播","value":52}],"unit":"万","caption":"预算主要投向搭建和传播"}
```
````

JSON 必须合法（双引号、无尾逗号）。各类型的字段见 `charts.md`。图片自动生成到 `charts/`。

## ```image 配图

````
```image
{"file":"images/stage.png","prompt":"……","ratio":"16:9","caption":"主舞台概念示意（效果图）","width":16}
```
````

| 字段 | 说明 |
|---|---|
| `file` | 图片路径（相对 proposal.md）。文件已存在就直接用 |
| `prompt` | 生图提示词，写法见 `visuals.md` |
| `ratio` | `16:9`（默认）/ `4:3` / `1:1` / `3:4` / `9:16` |
| `caption` | 图注，生成的图要带「示意」「效果图」字样 |
| `width` | 可选，宽度（cm），竖图建议 9—11 |
| `negative` | 可选，反向提示词 |
