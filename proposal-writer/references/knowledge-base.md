# 知识库目录

用户可以指定一个文件夹当知识库，放品牌资料、VI 手册、往期需求单和方案、价格表、站点清单、活动口径、logo、二维码、产品图、现场照片等。
写需求单或企划书前先到里面查，查到的事实和素材直接用。**没配置就跳过这一步，照常出稿，不要停下来问。**

**不限文件类型**：ppt、pdf、Word、Excel、图片、视频、设计源文件、聊天记录导出、压缩包……什么都可能有。
`kb.py` 只是帮你找文件、抽文字的工具，抽不出来的文件**要用你自己的能力打开看、自己分析**，不能因为脚本读不了就当它不存在。

## 每次任务开头

```
python <skill_dir>/scripts/kb.py status
```

- `configured: true` → 按下面「怎么查」去查。
- `configured: false` → 跳过，照常出稿。输出里 `remind: true` 时（第一次用，或配置的目录不存在），
  在交付消息**最后**加一句提醒（陈述句，不要问句）：
  「提示：可以给我指定一个文件夹当知识库（放品牌资料、往期方案、价格表、logo、二维码），以后出稿会先查里面的资料。直接把文件夹路径发给我就行。」
- 用户在对话里给了文件夹路径 → `python <skill_dir>/scripts/kb.py set <路径>`，然后接着做任务。

## 怎么查

1. 从需求里挑 3—6 个关键词：品牌名、物料类型（海报、宣传页、导视）、站点名、活动名、合作方、要用的素材（logo、二维码、产品图）。
2. `python <skill_dir>/scripts/kb.py list` 先看一眼目录结构和文件类型（`ext`），心里有数哪些文件可能相关。
3. `python <skill_dir>/scripts/kb.py search 关键词1 关键词2 …`：所有文件按文件名匹配；docx / pptx / xlsx / pdf / 各种纯文本还会搜正文。
   按 `score` 从高到低看。`text_extracted: false` 的命中（图片、视频、psd/ai 源文件、旧版 doc/ppt/xls……）只是文件名对上了，内容要你自己看。
4. 读内容：`python <skill_dir>/scripts/kb.py read <path>`（默认前 2 万字，`--max` 调整）。
   返回 `text_extracted: false` 时，按 `abs_path` 用你自己的能力打开：图片直接看图，PPT / PDF 看版式和图片内容，
   其他格式用平台的文件读取、转换能力；实在打不开就在交付消息里说一句哪个文件没读到。
5. 文件名对不上、但从目录和类型看可能相关的（如「2025 年物料」文件夹里的 pptx、「VI」文件夹里的图片），也要主动打开看。
   一般看 3—8 个最相关的文件就够，不要把整个目录读一遍。
6. 看完自己归纳：这次物料能用的事实（数字、文案、口径）、风格参考（往期版式、配色）、可直接用的素材（logo、二维码、照片）。

## 用法

- **事实优先级**：用户本轮消息 > 知识库 > 品牌档案（`brands/`）> 默认值。知识库和品牌档案对不上时用知识库的，
  在交付消息里用一句话说明「XX 按知识库《文件名》写的」。
- **往期需求单 / 方案**：照它的格式、口径、文案风格写；用户说「照上次那个做」时，先在知识库里找上次的文件。
- **数字**（价格、权益、桩数、尺寸、电话）：知识库里有就用，并记下出处文件名；没有照常走默认值或【待补】。
- **图片素材**：在 brief.md / proposal.md 里用 `kb:相对路径` 引用，例如 `![小程序码|4](kb:素材/小程序码.png)`。
  知识库里的 logo、二维码、产品图、现场照片**优先于**生成图和占位说明；二维码找到了就直接插，不用再写「设计方从源文件取」。
- 只读不改：不要往知识库目录里写文件、改文件，产物放工作目录。

## 安装后配置

三种方式任选一种：
- 对话里把文件夹路径发给 Agent，它会运行 `kb.py set`。
- 自己运行 `python <skill_dir>/scripts/kb.py set <文件夹路径>`（写入 `<skill_dir>/config.json`，不可写时写 `~/.proposal-writer/config.json`）。
- 设置环境变量 `PROPOSAL_KB_DIR=<文件夹路径>`（优先级最高）。
