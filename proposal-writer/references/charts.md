# 统计图（```chart）

## 先选图

| 要说明的事 | 用什么 | type |
|---|---|---|
| 时间进度、排期 | 甘特图 | `gantt` |
| 预算 / 构成占比（≤6 项） | 环形图 | `donut` |
| 排行、对比（类别名长） | 横向条形图 | `hbar` |
| 几个时期 / 几组对比 | 柱状图（可分组、可堆叠） | `bar` |
| 趋势（按月 / 年） | 折线图（≤5 条线） | `line` |
| 转化路径 | 漏斗图 | `funnel` |
| 敏感性分析（哪个变量影响最大） | 龙卷风图 | `tornado` |
| 多维打分对比（选址候选点、方案比选） | 雷达图（≤3 个对象） | `radar` |
| 只有两三个数字 | **不画图**，写进提示框或表格 | — |

一图一结论：`caption` 写这张图说明了什么（「预算主要投向搭建和传播」），不要写成「预算分布图」。

**数据从哪来**：
- 用户给了数据 → 照用。
- 方案自己定的数字（预算拆分、排期、KPI 目标、转化漏斗目标）→ 可以画，它们本来就是方案内容。
- 市场趋势、竞品声量、行业规模这类**外部事实**，用户没给 → **不画图、不编数字**，改用表格或文字写定性判断，
  并在附录里列为「待补充数据」。宁可少一张图，也不要放一张假数据图。

## 通用字段

| 字段 | 说明 |
|---|---|
| `type` | 必填 |
| `caption` | 图注，就是这张图的结论 |
| `title` | 可选，画在图内左上角。有 caption 时一般不用 |
| `unit` | 数值单位，如 `"万"`、`"%"`、`"人"`。不写单位时，过万的数字会自动显示成「x 万 / x 亿」 |
| `width` | 插入宽度（cm），默认 16.6 通栏。想让图矮一点就调小 |

## 各类型字段

**gantt**
```json
{"type":"gantt",
 "tasks":[{"name":"方案确认","start":"2026-12-01","end":"2026-12-15","group":"筹备"}],
 "milestones":[{"name":"发布日","date":"2027-03-15"}],
 "caption":"12 月启动，3 月 15 日发布"}
```
`group` 相同的任务同色；任务不超过 12 条，太细的合并。

**donut**
```json
{"type":"donut","items":[{"name":"搭建","value":78},{"name":"传播","value":52}],
 "unit":"万","center_label":"总预算","caption":"……"}
```
项数超过 6 时，把小项合并成「其他」。

**hbar / bar**
```json
{"type":"hbar","categories":["品牌 A","品牌 B","本品"],
 "series":[{"name":"声量指数","data":[86,72,41]}],
 "highlight":"本品","caption":"……"}
```
- 多系列：`series` 放多个 `{"name","data"}`，自动出图例。
- `"stacked": true` 堆叠，顶端标合计。
- `highlight`（只对单系列生效）：被强调的类别用主色，其余用灰色。适合「我们 vs 竞品」。

**line**
```json
{"type":"line","x":["2024","2025","2026"],
 "series":[{"name":"占比","data":[31,44,58]}],"unit":"%","caption":"……"}
```

**funnel**
```json
{"type":"funnel","items":[{"name":"曝光","value":30000000},{"name":"互动","value":1200000},{"name":"成交","value":3800}],"caption":"……"}
```
层宽按层级等步递减，不按数值比例；右侧标数值和环节转化率。

**参考线（line / bar 通用）**
```json
"hline":[{"value":0,"label":"回本线"}], "vline":[{"at":"第5年","label":"回本 4.6 年"}]
```
`hline` 画横向虚线（0 线、保本值、目标值）；`vline` 的 `at` 写 `x`（或 `categories`）里的某个标签。

**tornado**
```json
{"type":"tornado","base":6.2,"unit":" 年","lower_is_better":true,
 "items":[{"name":"日电量 ±30%","low":9.8,"high":4.5},{"name":"服务费 ±0.1 元","low":11.0,"high":4.1}],
 "caption":"回收期对服务费最敏感"}
```
`low` / `high` 是变量取不利 / 有利值时的指标值，按影响幅度自动排序；有利的一侧用主色。`lower_is_better` 用于回收期这类越小越好的指标。
一般不用手写：`finance.py` 会自动生成。

**radar**
```json
{"type":"radar","axes":["车流","电力","租期","竞品","配套"],"max":10,
 "series":[{"name":"候选点 A","data":[8,6,9,7,6]},{"name":"候选点 B","data":[7,9,5,8,7]}],
 "caption":"A 点胜在租期，B 点胜在电力"}
```
图例里自动附总分。打分和权重是方案自己定的，正文要写明「企业自定，无公开出处」。

## 配色

第 1 个类别用 frontmatter 的 `theme` 主色，和文档同色系；后面按固定顺序取色（蓝、橙、青、黄、粉、绿、紫、红，
已通过色盲校验），跟主色太接近的颜色会自动跳过。同一份企划书里，同一个类别在不同图里要保持同一位置，颜色才会一致。
`highlight` 的强调色也是主色。
