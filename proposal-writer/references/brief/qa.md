# 需求单交付前检查

有问题就改 `brief.md` 后重出。

## 品牌

- [ ] `brief.py` 输出的 `warnings` 为空
- [ ] 品牌名、定位语、广告语、地址和品牌档案一字不差；广告语用现行版
- [ ] 颜色写的是档案里的 VI 色，没有自创主色；联名物料两家 logo 都在
- [ ] 面向司机的物料 logo 用中文版

## 信息完整

- [ ] 头部有尺寸（或载体尺寸）、视觉基调、交付格式、时间
- [ ] 该类型「必须拿到」的信息都有，或已写成【待补】并列进「需提供的素材」
- [ ] 数字（价格、权益、桩数、尺寸、电话）都来自用户或品牌档案，没有编的
- [ ] 宣传页电话留白手填，文末有「最终解释权归场站所有」

## 设计师能直接开工

- [ ] 文案和设计说明分开：文案里没有「放大 / 做成卡片」，设计说明都在 `>` 里
- [ ] 要突出的关键词都加粗了，每个卖点只突出一处
- [ ] 每张配图都写了是什么类型的图，不只是「配一张 XX 图」
- [ ] 每个区域的底色、渐变、禁用色写清楚了
- [ ] 要去掉的元素明确写了「不要 / 去掉」
- [ ] 该类型的「常见返工点」都提前写进了设计说明
