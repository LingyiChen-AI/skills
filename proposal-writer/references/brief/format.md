# brief.md 语法

需求单源文件是 Markdown，渲染成用户惯用的 Word 格式：A4、无封面无目录，标题 → 头部信息 → 分区文案。
完整样例：[assets/example-brief-flyer/brief.md](../../assets/example-brief-flyer/brief.md)（宣传页）、
[assets/example-brief-station/brief.md](../../assets/example-brief-station/brief.md)（场站效果图 + 导视）。

## 两种文字必须分开写

需求单里有两种文字，设计师最容易搞混（改稿记录里设计师问过「这个单独再做一行是什么意思」）：

| 文字 | 是什么 | 写法 | 渲染效果 |
|---|---|---|---|
| **文案** | 要原样印到画面上的字 | 普通段落、`!!` 大字、`##` 小标题、表格 | 黑色 |
| **设计说明** | 只给设计师看的版式、颜色、配图要求 | `>` 引用块 | 蓝色加粗，前缀「设计说明：」 |

文案里不要夹「放大」「做成卡片」这类指令；设计说明里不要写要印出来的字。

## frontmatter

```yaml
---
title: 驰远超充 · 购车礼 A4 双面宣传页设计   # 必填：品牌 · 活动 / 对象 + 尺寸 + 物料 + 设计
brand: demo                  # 品牌档案目录名（brands/ 下），不写就用 brands/DEFAULT
type: 宣传页                 # 宣传页 / 场站效果图 / VI物料 / 办公空间 / 户外广告 / 改稿意见
size: 单张 A4（210×297mm），双面印刷
material: 300g 铜版纸，覆哑膜   # 可选：材质 / 工艺
quantity: 2000 份            # 可选
tone: 品牌主题色，突出“新能源、省钱、省心”   # 视觉基调：主色 + 要突出的 2—3 个词
reference: 导视套用B站        # 可选：参考物料 / 参考站点
deliver: 源文件 + JPG         # 不写默认「源文件 + JPG」
deadline: 2026-11-18 18:00    # 不知道就写【待补：交稿时间】
from: 品牌宣传部              # 可选，需求方
to: 设计方                    # 可选，设计方
date: 2026-11-16
filename: 自定义文件名        # 可选
---
```

头部按「尺寸 → 材质 / 工艺 → 数量 → 视觉基调 → 参考 → 交付 → 时间」顺序显示，没写的不显示。

## 正文

| 写法 | 用途 | 效果 |
|---|---|---|
| `# 正面文案` | 区块：正面文案、背面文案、正面底部行动号召、某个站、某类物料、需提供的素材 | 14pt 加粗，自动补「：」 |
| `## 购车直降礼` | 区块里的小标题（卡片名、小节名） | 14pt 加粗 |
| `### 小标题` | 更小一级 | 12pt 加粗 |
| `!! 驰远携手示例车企，联合推出` | **主标题类大字文案**，一行一句 | 18pt 加粗 |
| 普通段落 | 正文文案 | 12pt |
| `**送 ¥12000**` | 要突出的关键词（设计师据此提成大字或标签） | 加粗 |
| `1. xxx` | 编号要求（布局要求、修改意见） | 「1、」样式 |
| `- xxx` | 无序条目 | 「·」 |
| `\| 表格 \|` | 权益表、站点信息表、门牌清单、素材清单 | 灰表头、细框线 |
| `> 文字` | 设计说明 | 蓝色加粗「设计说明：」 |
| `> [!配图] 文字` | 配图要求（写清什么类型、什么底色） | 绿色加粗「配图：」 |
| `> [!待补] 文字` | 一段缺失信息 | 红色「待补：」 |
| `> [!注意] 文字` | 必须遵守的限制 | 红色「注意：」 |
| `【待补：现场照片】` | 行内缺失信息，会汇总进输出的 `todos` | 红色加粗 |
| `【留空白，手填号码】` | 版面上要留白的位置 | 灰底 |
| `![驰远超充 logo\|6](brand:logo.png)` | 插图；`\|6` 是宽度 cm；`brand:` 指向品牌档案目录 | 图上方带灰色小标签 |

**并排图**：连续几行图片、且每张都写了宽度、总宽 ≤ 16.6cm 时自动并排（联名 logo、两张产品图）。

**参考示意图**（可选，一般不用）：要给设计师一张方向参考、又没有现成图时，用 ```image 块生成，
字段同企划书（`file`、`prompt`、`ratio`、`caption`、`width`），图注必须写「参考示意，非定稿」。
需求单的核心是文字说清楚，不要用生成图代替说明；logo、产品图、现场照片、二维码**只能用用户给的**。
