# 物料类型模板

每类写了：**动笔前必须拿到的信息**、**需求单结构**、**这类物料常见的返工点**（来自真实改稿记录，写需求单时提前写进去，省掉一轮改稿）。
信息缺了照常写，缺的位置写 `【待补：xxx】`，并列进文末「需提供的素材」。

| 类型 | 典型说法 | 节 |
|---|---|---|
| 宣传页 / 海报 / 折页 / 单页 | 宣传页、DM 单、海报、易拉宝、展架、购车礼、活动单页 | §1 |
| 场站效果图 + 导视 | 效果图、新站、站点设计、导视、精神堡垒、入口牌、提示牌 | §2 |
| VI 应用物料 | 工服、马甲、手提袋、纸杯、名片、工作证、礼品 | §3 |
| 办公空间形象 | 办公室、形象墙、门牌、部门标识、会议室、文化墙 | §4 |
| 户外广告面 | 集装箱广告、围挡、墙体广告、楼体字、广告牌、车身贴 | §5 |
| 改稿意见 | 改一下、修改意见、反馈给设计、这版哪里不对 | §6 |

不属于以上的物料，按 §1 的结构写（尺寸 → 视觉基调 → 分区文案 → 配图 → 底部信息 → 交付）。

---

## §1 宣传页 / 海报 / 折页

**必须拿到**：尺寸与单 / 双面、印刷数量（可选）、活动主题和时间、卖点（数字要准）、联系方式和地址、要放的 logo（联名的话两家都要）、产品图。

**结构**（照用户的「购车礼 A4 双面宣传页」写）：

1. 标题：`品牌 · 活动名 + 尺寸 + 物料名 + 设计`，例：「润杰超充 · 购车礼 A4 双面宣传页设计」
2. 头部信息：尺寸、视觉基调（主色 + 要突出的 2—3 个词）
3. **正面文案**：logo 行 → 主标题（2—3 行大字） → 产品图（写「需设计整体效果」） → 卖点模块 → 正面底部行动号召 + 联系信息
4. **背面文案**：大标题（价值数字突出） → 一句副标题 → 权益 / 服务明细表 → 配图要求 → 收尾金句 → 背面底部行动号召 + 联系信息
5. 色彩分区说明、文末声明

**写法要点**：
- 卖点模块写清版式：「三大礼包用卡片形式，并排三卡，整体放大」。每张卡一个小标题 + 一两句文案，**要突出的关键词加粗**，
  并写设计说明「加粗的关键词单独提出来做大字 / 标签，一眼能看到」。
- 明细表（权益、价格、服务）用表格，表头固定：项目 | 价值标准 | 周期 | 说明。
- 配图要求**逐项写清是什么样的图**：不只写「配住宿图」，要写「宿舍类型图片：上下铺、明亮干净」；不只写「导航」，要写「正常导航界面截图，白色底图」。
- 底部固定两样：行动号召（「三重大礼 · 限时放送 │ 名额有限 · 先到先得」这种对仗短句）+ 咨询热线（留空白手填）| 门店 / 电站地址。
- 文末固定：「最终解释权归场站所有」（活动类物料）。

**常见返工点**（2026 购车礼宣传页改了 6 轮）：
- 卖点卡片太小、关键词不突出 → 需求单里直接写「整体放大，关键词单独成行或做成标签」。
- 配图不贴场景（住宿配了酒店图、导航配了花哨的地图） → 配图要求写到「什么类型的图、什么底色」。
- 电话写死了又要删 → 号码一开始就写「留空白，手填号码」。
- 底部颜色反复改 → 一开始就写清每个区域的底色和渐变方向。
- 漏了声明 → 「最终解释权归场站所有」默认写上。
- 交付：源文件 + JPG。

## §2 场站效果图 + 导视

**必须拿到**（缺一样设计方就会回来问）：
- 站名（格式「润杰重卡超充 XX站」）、**现场照片**、平面规划图或布局示意、场地尺寸
- 充电桩数量（**要在效果图上体现**）、车位（重卡 / 小车）数量
- 运营用房：层数、间数、位置（靠路边 / 出入口哪一侧）、门牌
- 出入口形式：道闸 or 敞开式；围栏要不要；地面（水泥硬化 / 碎石）
- 导视：精神堡垒 / 高炮 / 入口牌用哪种；**套用哪个站的导视**（见品牌档案 §4）
- 附属：晾衣架、电动车位、雨棚、站外提示牌

**结构**：
1. 标题：「润杰重卡超充 XX站 效果图及导视设计」（多个站写在一张单里，每站一节）
2. 头部信息：交付物（效果图 + 导视平面设计稿 / 制作文件）、视觉基调（VI 色）、参考站点
3. 每个站一节：基本信息表（站名、桩数、车位、用房、出入口、地面） → 布局要求（逐条编号） → 导视要求（套用哪站、站名怎么写、新增哪些牌）
4. 站外提示牌（如有）：尺寸、颜色、文案、logo 位置。例：2×3m，品牌色，左上角 logo，正文「重卡充电站，前方 500 米」，设在距入口 500 米处
5. 需提供的素材

**写法要点**：
- 布局要求逐条编号写成「对象 + 位置 / 数量 + 做法」，一条一个改动，例：
  「1. 运营用房做两层，放在出口一侧并尽量靠路边」「2. 在充电位停放的重卡车头一律朝向充电桩」。
- 要去掉的东西写明「不要」：「不做精神堡垒，改双面铁板入口牌」「去掉四周围栏」「不需要道闸」。
- 导视写「全套导视按 XX 站的导视清单数量出，站名换成本站」，不用另列清单。
- 效果图和导视设计稿**一起交**（要上会确认）；导视出制作文件。

**常见返工点**（新都桥 / 河源灯塔站改了 3 轮）：运营用房位置和层数、出入口道闸、桩数没体现、车头朝向、
围栏和地面材质、入口牌形式、导视用 VI 色还是沿用参考图颜色（答：用 VI 色）、误放了别处（深圳办公室）的元素。

## §3 VI 应用物料

**必须拿到**：物料清单（每项的款式参考图）、颜色、logo 版本、要不要定位语 / 广告语、工艺材质（如纸杯 300g 淋膜纸）、数量。

**结构**：
1. 标题：「润杰超充 VI 应用物料设计（服装 / 手提袋 / 纸杯）」
2. 头部信息：范围（引用品牌档案 §8 的目录编号，如「B1 全部；B2 环境标识按站点分解；B3 服装按选定款式改」）、视觉基调
3. 每类物料一节：款式（插用户给的参考图）→ 颜色 → logo 位置 → 文字内容 → 出几个版本
4. 交付：源文件 + JPG；**服装单独一个源文件**

**写法要点与返工点**：
- 服装：logo 红 + logo 灰**双色**；反光马甲黄 + logo 灰；logo 用**中文版**；logo 位置参考用户给的样衣（如特斯拉工服）。
- 手提袋：logo 和定位语**不能分开**，按用户指定的排列方式；提手红色；袋身上方文字用现行广告语。
- 纸杯：一次出全组合——红杯 / 白杯 × 有定位语 / 纯 logo；定位语在 logo **正下方**，一行，可比 logo 宽。
- 字号：定位语、广告语改稿时反复被要求「调大」，需求单里直接写「字号要大，正面一眼可读」。

## §4 办公空间形象

**必须拿到**：地点、**现场照片 + 墙面尺寸**、平面图、部门名称、门牌清单、每面墙放什么、要不要报价。

**结构**：
1. 标题：「润杰超充 XX 办公室形象设计」
2. 头部信息：范围（大厅 / 会议室 / 门牌 / 形象墙）、视觉基调（VI 色）、交付（效果图 + 报价）
3. 按空间分节：大厅（部门标识，注意**部门标识不是门牌**）→ 会议室（每面墙的内容、哪面上方不放东西）→ 形象墙（标题、英文、材质）→ 门牌（清单表：中文 | 英文 | 规格）
4. 需提供的素材

**返工点**（深圳办公室）：漏了会议室需求、团队风采英文、地图还是旧颜色、地图多余的一块、软板材质、把部门标识当成门牌。
门牌规格沿用：30×15cm 亚克力 UV 侧面抽插式。

---

## §5 户外广告面

**必须拿到**：载体与**尺寸**（集装箱长 × 宽 × 高、几层）、**正面照片**（有楼梯、门窗要避开的）、观看距离、文案、二维码 / 电话、颜色。

**结构**：
1. 标题：「XX 广告面设计」
2. 头部信息：尺寸、视觉基调、制作工艺（如有）
3. 分区文案：按物理分区写（上层 / 下层、左面 / 右面）。例：上层放标题、副标题、小程序码、电话；下层放服务项目
4. 图标说明（服务项目逐个配图标；电话用 24 小时图标）
5. 避让说明：内容避开楼梯、门窗；没有精确尺寸时写「先目测按照片排，避开楼梯」

**返工点**（车辆服务中心集装箱）：没说清两层分别放什么、楼梯遮挡、电话图标、小程序码旁文字没对齐。户外文字要**少而大**，标题不超过 10 个字。

## §6 改稿意见

用户发来设计稿要提修改意见时，按这个格式写（贴到群里或附在需求单后面）：

```
@设计方 XX 修改意见：
XX站：
1、地面除了出入口做水泥硬化，其余都铺碎石。
2、运营用房周边加晾衣架。
3、不做精神堡垒，改成双面铁板入口牌。
```

- **一条只说一个改动**：位置 + 改成什么。「圈起来那三个框整体放大」比「再优化一下」有用。
- 设计方看不懂的说法要换成具体做法：「关键词单独再做一行」→「把『送 ¥12000』『低首付』『省 4000—6000 元』做成大字标签放在卡片顶部」。
- 有截图就配截图，在需求单里写 `![修改位置](截图路径)`。
- 多个对象（多个站、多个物料）分组写，每组单独编号。
- 末尾写交付要求：「改完发源文件和 JPG」。
