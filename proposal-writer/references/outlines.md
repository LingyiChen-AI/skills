# 大纲模板

每章写明：**这一章回答什么问题** / 写什么 / 推荐的视觉元素。按需删减，不要为了凑篇幅保留空章节。
所有模板的第一章都是「项目概述」，最后一章（可选）都是「附录：假设与待确认事项」。

有行业包的行业用行业包的大纲：超充站 / 充电站 → [industry/supercharging.md](industry/supercharging.md)（建站可研、补贴申报、场地合作、开业活动、年度运营五类）。

## 活动企划（发布会、年会、快闪、展会、路演、促销活动）

| 章节 | 回答的问题 | 写什么 | 推荐视觉 |
|---|---|---|---|
| 项目概述 | 一页看懂要做什么 | 一句话方案、时间地点规模、核心目标数字、总预算 | 提示框 + 信息表 |
| 背景与目标 | 为什么要办 | 业务背景、要解决的问题；目标拆成品牌 / 销售 / 传播三类，每条带数字 | 趋势图或对比图（有数据时） |
| 受众洞察 | 来的人想要什么 | 人群画像、参与动机、顾虑；一条核心洞察 | 画像表 + 洞察提示框 |
| 核心创意 | 用什么点子打动人 | 主题名称、主题释义、创意如何对应洞察 | 主视觉 / 空间概念图（生图） |
| 活动内容与体验动线 | 现场怎么玩 | 分区或流程，每段写清：做什么、停留多久、参与者得到什么 | 动线 / 分区示意图（生图），流程表 |
| 节目 / 议程（按需） | 台上演什么 | 时间段、环节、负责人、时长 | 议程表 |
| 传播计划 | 怎么让更多人知道 | 预热 / 爆发 / 长尾三阶段，渠道、内容、节奏 | 转化漏斗图，渠道表 |
| 执行排期 | 什么时候做完什么 | 从立项到复盘的里程碑 | 甘特图 |
| 预算 | 钱花在哪 | 科目、金额、占比、说明；预留 5%—10% 不可预见费 | 环形图 + 预算明细表 |
| 效果评估 | 怎么算成功 | 每个目标对应指标、目标值、统计口径 | KPI 表 |
| 风险与应对 | 出问题怎么办 | 审批、天气、人流、设备、舆情等，写具体应对动作 | 风险表 |

合并建议：「节目 / 议程」只在有舞台环节时保留；「受众洞察」可并入「背景与目标」；「效果评估」和「风险与应对」可合并。

## 营销 / 推广方案（campaign、品牌传播、大促）

| 章节 | 回答的问题 | 写什么 | 推荐视觉 |
|---|---|---|---|
| 项目概述 | 一页看懂 | 一句话策略、周期、预算、核心 KPI | 提示框 + 信息表 |
| 市场与现状 | 我们在哪 | 品类趋势、品牌现状（声量、份额、口碑）、关键问题 | 趋势折线图、对比条形图 |
| 目标人群 | 对谁说 | 核心人群与次要人群，场景、痛点、信息渠道 | 画像表 |
| 竞品分析 | 别人怎么做 | 2—4 个竞品的打法、优劣，我们的机会点 | 对比表、突出本品的条形图 |
| 策略与核心信息 | 说什么 | 核心主张（一句话）、支撑点（3 个以内）、语气 | 洞察提示框 |
| 创意与内容 | 怎么说 | 主题、主视觉方向、内容系列（形式、数量、示例标题） | 主视觉 / 海报方向图（生图） |
| 渠道与投放 | 在哪说、花多少 | 渠道组合、各渠道角色、投放节奏与预算占比 | 预算分配条形图或环形图 |
| 转化路径 | 怎么变成生意 | 曝光 → 互动 → 进店 / 进页 → 成交，各环节承接动作 | 转化漏斗图 |
| 执行排期 | 节奏 | 预热 / 爆发 / 长尾里程碑 | 甘特图 |
| 预算 | 钱花在哪 | 明细表 | 环形图 + 表 |
| 效果评估 | 怎么算成功 | KPI、口径、复盘节点 | KPI 表 |
| 风险与应对 | 出问题怎么办 | 投放效果不及预期、舆情、竞品截流 | 风险表 |

合并建议（12 章 → 8—10 章）：「目标人群」+「竞品分析」并成「洞察分析」；「转化路径」并入「渠道与投放」；
「执行排期」可并入「渠道与投放」或「预算」前；预算较小时「效果评估」和「风险与应对」并成「效果评估与风险」。

## 产品 / 新品上市企划（GTM）

| 章节 | 回答的问题 | 写什么 | 推荐视觉 |
|---|---|---|---|
| 项目概述 | 一页看懂 | 产品是什么、何时上市、目标、预算 | 提示框 + 信息表 |
| 产品介绍 | 卖的是什么 | 核心卖点（3 个以内）、规格、定价、和老品的区别 | 产品场景图（生图）、卖点表 |
| 市场机会 | 为什么现在做 | 需求趋势、目标市场规模、空白点 | 趋势图 |
| 目标用户与场景 | 谁会买、在什么时候用 | 人群、使用场景、购买动机 | 画像表、场景图 |
| 竞品与定位 | 凭什么选我们 | 竞品对比、定位语、价格带 | 对比表、价格带条形图 |
| 上市节奏 | 分几步走 | 预热、首发、放量三阶段，每阶段的目标和动作 | 甘特图 |
| 渠道与销售策略 | 在哪卖 | 渠道角色、铺货节奏、促销政策 | 渠道表 |
| 传播计划 | 怎么让人知道 | 首发事件、内容、达人、投放 | 漏斗图 |
| 预算与销售目标 | 投入产出 | 费用预算、销量 / GMV 目标、投入产出比 | 预算环形图、目标柱状图 |
| 风险与应对 | — | 供应链、价格战、口碑 | 风险表 |

## 通用企划（立项、改进方案、内部项目）

| 章节 | 回答的问题 | 写什么 | 推荐视觉 |
|---|---|---|---|
| 项目概述 | 一页看懂 | 要做什么、为什么、投入多少、预期收益 | 提示框 + 信息表 |
| 现状与问题 | 痛在哪 | 现状数据、问题清单、问题造成的损失 | 对比图、问题表 |
| 目标 | 做到什么程度 | 可衡量的目标，带时间 | 目标表 |
| 方案 | 怎么做 | 方案思路、关键举措（3—5 项），每项写做什么、谁做、产出什么 | 流程示意图、举措表 |
| 实施计划 | 什么时候做 | 阶段与里程碑 | 甘特图 |
| 资源与预算 | 要什么 | 人、钱、系统 | 预算表 / 环形图 |
| 预期收益 | 值不值 | 收益测算、回本周期 | 柱状图 |
| 风险与应对 | — | — | 风险表 |
